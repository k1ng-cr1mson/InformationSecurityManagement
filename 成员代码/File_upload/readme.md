# 用户文件管理系统

## 项目概述
本项目是一个基于 Flask 框架的用户文件管理系统，支持用户注册、登录、文件上传和查看等功能。同时，系统还提供了管理员界面，管理员可以查看所有用户的信息和他们上传的图片。

## 功能特性
- **用户注册与登录**：用户可以注册新账号，并使用注册的用户名和密码登录系统。
- **文件上传**：已登录的用户可以上传允许类型的文件（如 txt、pdf、png、jpg 等）。
- **文件查看**：用户可以查看自己上传的文件，图片文件会直接显示，其他文件会显示其文本内容。
- **管理员界面**：管理员可以查看所有用户的信息，包括每个用户上传的图片数量和部分图片。

## 技术栈
- **后端**：Flask 框架，MySQL 数据库
- **前端**：HTML、CSS（可根据需要添加）
